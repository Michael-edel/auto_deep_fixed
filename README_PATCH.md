# Патч: обработка ПАПКИ в main.py

## Что исправлено
Теперь можно запускать на папке:

```powershell
python main.py invoices
```

Скрипт найдёт все *.pdf/*.jpg/*.png (включая подпапки), обработает их по очереди и сохранит:
- `out/<имя_файла>.json` — результат для каждого документа
- `out/result_all.json` — общий файл со списком документов и ошибок (если были)

## Как применить
Замените файл `main.py` в корне проекта AUTO_Deep на `main.py` из этого патча.
(Остальные файлы не нужно трогать.)

## Пример
```powershell
python main.py "C:\Projects\AUTO_Deep\invoices"
```
